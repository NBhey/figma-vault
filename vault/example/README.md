# vault/example — фикстура (T2)

Это **самодостаточный корень vault**, написанный руками по `docs/CONTRACT.md` (`figma-vault/doc@0`).
Нужен для того, чтобы обе половины системы (экспортёр `src/pull` и MCP-сервер `src/mcp`)
проверялись без токена Figma и без сети.

```
vault/example/            <- корень vault (аналог ./vault в боевом режиме)
  index.json
  EXAMPLE1234_1_1/
    doc.json              <- макет «Sign in / Mobile», 29 узлов
    screenshot.png        <- рендер корневого узла, 375x812
    assets/logo.svg       <- vector-ассет узла 1:3
    assets/hero.png       <- растровый ассет узла 1:5
```

Запуск MCP-сервера против фикстуры:

```
npm run mcp:example
```

Что осознанно отличается от боевой выгрузки:

- нет `raw.json`: сырого ответа Figma не существует, узлы написаны вручную.
  Инвариант 9 контракта разрешает это — MCP-сервер к `raw.json` не обращается.
- `screenshot.png` нарисован программно по тем же координатам, что и в `doc.json`
  (текст показан плашками). Это не экспорт из Figma, а эталон геометрии:
  по нему проверяется, что агент восстановил раскладку, а не шрифтовой рендеринг.
- `source.figmaVersion` — нули, файла с таким `fileKey` в Figma нет.

Координаты фикстуры согласованы с инвариантами 1–9: `x`/`y` относительны родителю,
auto-layout выставлен только там, где есть `mode: row|column`, скрытых узлов нет.
