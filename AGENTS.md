# Протокол совместной работы агентов

Этот файл читают **все** агенты (Codex читает AGENTS.md автоматически, Claude — через CLAUDE.md).
Человек не является каналом связи. Всё, что нужно сказать другому агенту, пишется в файл.

Участники: `claude`, `codex`. Имя агента = его подпись во всех записях.

## 0. Ритуал каждой сессии

Перед работой, в этом порядке:
1. `AGENTS.md` (этот файл)
2. `docs/LOG.md` — последние 3 записи
3. `docs/BOARD.md` — что свободно
4. `docs/CONTRACT.md` — текущая замороженная версия формата

После работы, обязательно:
1. обновить статус задачи в `docs/BOARD.md`
2. дописать запись в конец `docs/LOG.md`
3. закоммитить

Сессия без записи в LOG считается не состоявшейся: другой агент о ней не узнает.

## 1. Владение файлами

Правка чужих файлов запрещена. Владение указано в `docs/BOARD.md` и здесь:

| путь | владелец |
|---|---|
| `src/mcp/**` | claude |
| `src/pull/**` | codex |
| `src/shared/**` | claude (codex только читает) |
| `vault/example/**` | claude |
| `docs/CONTRACT.md` | общий, особый режим (см. §3) |
| `docs/BOARD.md`, `docs/LOG.md` | общий, только свои строки |
| `package.json` | общий, но только добавление в `dependencies` |
| остальной корень (`tsconfig.json`, `.gitignore`) | claude |

Нужен файл в чужой зоне — не создавай его, опиши потребность в LOG и возьми другую задачу.

## 2. Захват задачи

Задача берётся правкой `docs/BOARD.md`: в колонку `owner` пишется имя, в `claimed` — UTC-время.
Одна задача в работе на агента. Коллизия захвата: **побеждает более раннее время**;
при равном времени побеждает имя, которое раньше по алфавиту (`claude`). Проигравший молча берёт другую задачу.

Если существует два конкурирующих набора протокольных файлов (оба агента создали свой) —
побеждает более ранний по времени коммита/создания. Второй агент удаляет свой и переходит на чужой. Без обсуждения.

## 3. Контракт

`docs/CONTRACT.md` — единственная точка связи между двумя половинами системы.
Раздел «Заморожено» не редактируется. Любое изменение — новая запись в разделе «Предложения»
с подписью и обоснованием. Другой агент на своём следующем ходу пишет `ПРИНЯТО` или `ОТКЛОНЕНО: причина`.
Принятое переносится в «Заморожено» с новым номером версии. До принятия код пишется под замороженную версию.

Спор решается так: выигрывает вариант, который проще восстановить агенту по макету (см. цель в `docs/IDEA.md`).
Если после двух обменов согласия нет — вопрос в LOG под заголовком `ВОПРОС К ЧЕЛОВЕКУ`, и оба берут другие задачи.

## 4. Коммиты

- формат: `[claude] T4: краткое описание` / `[codex] T3: ...`
- коммит после каждой завершённой задачи, не реже
- запрещено: `rebase`, `--force`, `--amend` и откат чужих коммитов
- конфликт слияния в общем файле разрешается сохранением **обеих** записей

## 5. Что не делать

- не спрашивать человека о том, что решается контрактом
- не блокироваться в ожидании другого агента: взять следующую незаблокированную задачу
- не расширять MVP за рамки ограничений из `docs/IDEA.md`
- не переписывать чужие записи в LOG

## 6. Автономный режим

Каждый агент работает на собственных часах (Claude — навык `/loop`, Codex — `scripts/codex-loop.ps1`).
Агенты запускаются параллельно и независимо, человек в цикле не участвует.

**Цикл одного хода:**
1. `git log --oneline -5` и `git status` — увидеть работу другого агента с прошлого хода.
2. Прочитать хвост `docs/LOG.md` и `docs/BOARD.md`.
3. Ответить на всё, что адресовано тебе: вердикт по «Предложениям» в контракте, вопросы в LOG.
4. Взять **одну** свободную задачу, закрыть её, закоммитить.
5. Дописать запись в `docs/LOG.md`.

**Гонка при захвате.** Агенты работают одновременно, поэтому `docs/BOARD.md` перечитывается
непосредственно перед записью захвата. Если строка уже занята другим — молча взять следующую свободную.
После захвата сразу коммит, чтобы захват стал виден другому.

**Условие остановки.** Если свободных задач нет, все «Предложения» получили вердикт и вопросов
в свой адрес нет — агент дописывает в LOG строку `IDLE: свободных задач нет` и **останавливает цикл**.
Не выдумывать себе работу, не расширять MVP, не рефакторить чужие каталоги ради занятости.

**Когда всё-таки звать человека.** Только три случая: нужен секрет (`FIGMA_TOKEN`); нужно
внешнее решение о продукте, которое не выводится из `docs/IDEA.md`; два агента дважды не сошлись
по контракту. Запись в LOG под заголовком `ВОПРОС К ЧЕЛОВЕКУ`, после чего взять другую задачу
и продолжать, не дожидаясь ответа.
