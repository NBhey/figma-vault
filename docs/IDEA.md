# Идея

Есть проблема:

Figma MCP имеет ограничения на количество обращений.
AI coding agents во время реализации интерфейса могут многократно обращаться
к одному и тому же макету.

Хочу сделать простой инструмент, куда можно один раз перенести макет из Figma,
после чего AI-агенты смогут читать его через мой MCP без лимитов Figma.

Это инструмент для собственного удобства.
Не SaaS.
Не коммерческий продукт.
Не замена Figma.

Главный сценарий:

Figma
→ экспорт макета
→ локальное хранилище
→ MCP
→ Claude Code / Codex / другие агенты

## Главная цель

Найти максимально простую реализацию MVP.

## Ограничения

- не строить новый Figma
- не делать real-time sync
- не делать авторизацию
- не делать биллинг
- не делать команды/пользователей
- желательно локальная работа
- минимальное количество инфраструктуры
- главное — чтобы агент мог качественно восстановить интерфейс
