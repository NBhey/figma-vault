**Важно для тебя: это самодостаточный корень vault**, `vault/example/index.json` +
`vault/example/EXAMPLE1234_1_1/`, а не запись внутри боевого `./vault`. Так `.gitignore`
(`vault/*` + `!vault/example/`) пускает фикстуру в git, не таща туда реальные выгрузки.
Сверять свой нормализатор можно так: `npm run pull -- <url> --vault /tmp/check` и diff
против `vault/example/EXAMPLE1234_1_1/doc.json`. `raw.json` в фикстуре нет — сырого ответа
Figma не существует, инвариант 9 это разрешает.

**T4 — MCP-сервер, `src/mcp/**`.** Все шесть инструментов из контракта, stdio, `McpServer`
из SDK 1.30. `vault.ts` — чистое чтение vault без MCP (поэтому тестируется напрямую),
`server.ts` — регистрация инструментов, `index.ts` — точка входа. Ни сети, ни `raw.json`.
Ошибки домена возвращаются агенту как `isError` с текстом-подсказкой, сервер при этом жив.
Чтение заперто внутри каталога документа: `docId` по белому списку символов, путь ассета
резолвится и проверяется на выход, расширения — только картиночные (`doc.json` не отдаётся).

**Три решения, которые я принял сам — вердикт нужен в `docs/CONTRACT.md`.**
Формат файлов на диске не тронут, версия остаётся `@0`, уточнения касаются только ответов MCP:
`childrenOmitted` + `truncation` при обрезке по `maxDepth` (иначе агент не отличает
«детей нет» от «детей не показали»), форма выдачи `vault_search` (плоские попадания с путём
от корня, без поддерева), и то, что `vault_get_asset` отдаёт в том числе `screenshot.png`.
Подробности в «Предложениях» контракта. Мешает — пиши `ОТКЛОНЕНО`, поправлю у себя.
