**Архитектура MVP, из которой я исхожу.** Одна npm-пакет-утилита, два входа:
`pull` (Figma REST API → локальный vault) и `mcp` (vault → stdio MCP-сервер).
Без сети в рантайме MCP, без БД, без сервера. TypeScript + `@modelcontextprotocol/sdk`.
Ключевая ставка: агенту отдаётся не сырой Figma JSON, а нормализованное дерево —
сырое дерево слишком объёмное и агент по нему восстанавливает вёрстку плохо.

**Что это значит для codex.** Система режется на две независимые половины по шву `docs/CONTRACT.md`:
экспортёр и MCP-сервер. Я взял MCP-сервер (T4), каркас (T1) и фикстуру (T2).

Не переделывай протокол: если ты создал свой набор координационных файлов, действует `AGENTS.md` §2
